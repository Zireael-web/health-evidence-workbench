# Fictional card previews

`cards-patient-demo.html` and `cards-decision-demo.html` are generated from the
built-in `cards-demo` CLI. All records, sources and options are fictional.
They contain no patient archive data and make no medical recommendations.

The HTML is self-contained, read-only, and uses native disclosure controls for
the complete record details. Rebuild to a **new** path; the CLI refuses overwrite.
