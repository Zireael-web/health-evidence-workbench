# Synthetic document fixtures

All documents and values are invented specifically for engineering tests. They
contain no real patients, findings or diagnostic recommendations. Artificial
marker names and units are placeholders, not physiological measurements.
The generator emits valid, selectable-text PDF files and an `expected.json`
page-by-page oracle into a **new** folder. It refuses an existing destination.

```sh
python tests/synthetic_workflow/generate.py /absolute/path/to/new-test-folder
python -m pytest tests/synthetic_workflow
```

The PDF validation test needs the optional `documents` dependency (`pypdf`);
without it, that test is skipped and must not be reported as passing. No PDF
binaries or generated artifacts need to be committed. The PDF set exercises a
two-page numeric panel, an indeterminate qualitative result, a written
examination report without images, and a report with an unreadable result.

The automated tests check PDF parsing and exact extracted source lines, and
exercise the PDF copy/transcript helpers with three arbitrary explicitly
selected profile roots, repeat attempts, conflict preservation and file modes.
One test invokes the real `health-document` and `health-files` CLI in subprocesses
against an ephemeral three-profile configuration, checking explicit selection,
copy, transcript, repeat, cross-profile search isolation and coverage output.
Another invokes `health-duplicates` against two profiles: a renamed byte-identical
PDF matches, a one-byte change does not, the other profile is ignored, and a
skipped symlink makes the scan incomplete.
One test creates a new neutral folder via `health-document ensure-folder`, saves a
synthetic report and supplied transcript there, and searches only its selected
profile, verifying that no folder or search result appears in the other profile.
The transcript is passed directly by the test: it is **not** generated by a
model. The storage helper does not determine subject identity. These tests do
not exercise clinical interpretation, visual recognition, automatic selection
of a person, image-only documents, completeness of the archive search, external
source retrieval, or the chat workflow.
There is no claim of human or clinician verification.

For visual evaluation, render all pages and submit only these fictional PDFs to
the actual model, compare each returned field with `expected.json`, record
omissions and uncertain readings, and separately review the interpretation and
source alignment with appropriate clinical expertise. Native PDF text passing
the automated check does not establish visual recognition accuracy.
